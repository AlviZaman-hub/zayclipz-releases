# ZayClipz

Finds the most viral moments in long videos and sends them to CapCut as fully editable projects.

## Download
Go to **[Releases](../../releases/latest)** and download **ZayClipz-Setup-x.y.z.exe**. Open it and follow the steps.

- Windows 10 or 11, and CapCut for PC.
- You need a **license key** to use it. Ask the person who gave you ZayClipz.
- You'll add your own **Gemini API key** (free at aistudio.google.com/apikey) - you pay Google for what you use.
- Optional: a free **Pixabay key** for B-roll (pixabay.com/api/docs).

If Windows says **"Windows protected your PC"**, click **More info** → **Run anyway**.

ZayClipz updates itself: Settings → About → Check for updates.

Only clip videos you're allowed to clip - for example a campaign's source videos.
